# STAZA Next.js migration

This branch establishes a real Next.js App Router entry point and Vercel framework configuration, separate from the original Grok Build / TanStack Start runtime.

## Current state

- Next.js App Router shell and metadata are in `app/`.
- The original TanStack Start app, SQL migrations, seed data, and auth implementation are retained for a controlled migration; they are not yet wired into the Next.js routes.
- `/explore` and `/host` are explicit placeholders, not production implementations. Do not merge this branch as a completed migration until listing CRUD, booking links, favorites, Better Auth, database connection, admin permissions, API handlers, and route smoke tests are ported and verified.
- Vercel should install dependencies from `package.json`; the old lockfile is removed in this migration commit because the Next.js dependency is not yet represented there. A fresh npm lockfile should be generated by CI before production promotion.

## Required production environment

Use a managed PostgreSQL service (e.g. Neon) with `DATABASE_URL`. Do not rely on the original in-memory/PGlite fallback in serverless production. Configure Better Auth's public URL and production OAuth credentials only after its callbacks have been migrated to Next.js route handlers.
